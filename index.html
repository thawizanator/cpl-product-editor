ℹ️ About

Product License Editor

A single-file, local HTML tool for editing products.json mod config files for Supermarket Simulator (CustomProductsLoader 2.1.2+). Includes a 3D box placement visualizer, grid layout import, and Google Sheets converter.

By ThaWizanator · No install required · Runs 100% locally

📂 File Workflow

Open File… — Opens products.json directly from disk. In Chrome/Edge this enables one-click Save back to the same file.

🔗 Link to File for Direct Save — Appears when you loaded data via paste/import. Pick the target file to enable direct saving.

Import / Export JSON — Paste JSON to load, or copy current data as text.

📐 Import Grid Layouts — Loads ProductGridLayouts.json from the CustomProductGrids mod and merges matching product positions by Product ID.

📐 3D Box Visualizer

Click "📐 Open 3D Box Visualizer" inside the Grid Layout In Box section to open the placement tool.

• Drag to rotate, Right-click drag to pan, Scroll to zoom.

• Double-click a slider label to type an exact value.

• Double-click a slider to reset it to its default.

• Box dimension sliders are preview only — they set the visual reference box size but don't affect the saved boxSize value (use the Box Preset dropdown for that).

• Click 💾 Save to Grid Layout to write values back into the editor fields.

🌐 Browser Compatibility

Chrome / Edge / Brave — Full support including direct file save and folder pickers.

Firefox / Safari — Works, but direct save falls back to download, and folder pickers fall back to basic file dialogs.
